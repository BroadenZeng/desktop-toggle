# DesktopToggle 桌面切换

Windows 11 x64 的单文件、免安装工具。双击启用，再次双击关闭。默认单独按 **Tab** 在任务视图中第 1、2 个虚拟桌面之间切换。在第 3 个及以后的桌面触发时回到第 1 个。按当前排列顺序识别，不按桌面自定义名称识别。

## 使用

1. 下载 `DesktopToggle.exe`，放在任意文件夹，直接双击，无需管理员权限。
2. 启用后显示“已开启”窗口及托盘图标，Tab 用于切换桌面。只有一个桌面时会自动新建第二个。窗口提供“更改按键”“隐藏窗口”“关闭工具”。隐藏或关闭状态窗口只隐藏提示，工具继续运行；点击“关闭工具”才停止。
3. 再次双击 EXE 关闭；也可右键托盘图标选择“关闭并恢复按键”。
4. 在主窗口点击“更改按键”（或托盘菜单中的“更改按键…”），**直接按一下想用的键，再用鼠标点“保存按键”**。例如 Tab、F8、Caps Lock，也支持字母、数字、方向键及常见标点键。只支持单键，不录入组合键。录入期间暂停接管；保存后立即生效，主窗口保持显示并提示“已保存”。点击“取消更改”保留原键。输入框聚焦时 Enter、Esc、Tab 也用于录入，不用于保存、取消或跳转。

**Tab 会被占用**：启用默认配置后，单独 Tab 不能再用于缩进或移动焦点。默认配置放行 Alt+Tab、Ctrl+Tab、Shift+Tab。需要保留 Tab 时建议改成 F8。自定义快捷键也会占用原有功能，请避开常用组合。长按只触发一次，切换期间重复触发不排队；按住超过 4 秒时停止工具并提示。

关闭程序不会删除桌面、关闭窗口或结束其他应用。无开机启动、联网、更新服务或键盘内容日志。不要同时运行旧 BAT/PS1 版本。

## 系统与限制

- 适用于 **Windows 11 x64**，使用系统自带 .NET Framework 4.x，不需额外安装运行时，无第三方 DLL。不承诺 ARM64 原生支持。
- EXE 未签名，下载后可能出现 SmartScreen 提示。请从可信来源获取并核对 SHA256，无需关闭安全软件。
- 沿用原脚本方案：读取 Explorer 的桌面 GUID 状态，发送系统桌面快捷键，再等待状态变化确认。注册表布局是非公开实现细节，Windows 更新可能改变它，不能保证所有 Windows 11 版本兼容。
- 状态无效、发送失败或切换未确认时，停止接管并提示，不猜方向、不盲切。Explorer 重启期间可能需要重新启用。
- 管理员窗口、锁屏、安全桌面、远程桌面和第三方键盘工具可能限制输入。这些场景尚未验证；工具不会自动提权。
- 忽略标记为注入的模拟按键，防止递归；某些宏和辅助输入软件的 Tab 因此不会触发。
- 正常退出主动移除钩子。没有后台服务或永久按键映射。Windows 也可能因钩子超时自行移除它，此时原键放行，可重新启用。
- 配置：`%LOCALAPPDATA%\DesktopToggle\hotkey.txt`，内容为单个虚拟键码，默认 `9`。建议通过界面修改。最后一次错误保存在同目录 `last-error.txt`，不记录输入内容。
- 卸载：先关闭程序，再删除 EXE；删除上述配置目录可重置设置。

2026-11-15，Windows 11 x64 **22000.2538（21H2）**：

- 编译成功，警告视为错误。
- 实际从 **1 个桌面自动创建为 2 个**。

- 首次启动驻留，第二次启动令第一实例退出；模拟强制终止后能重新启动和关闭。

**尚未实测**：新的按键录入与保存界面、真人物理键盘 Tab 的完整拦截/放行与焦点行为、管理员窗口、锁屏、远程桌面、其他 Windows 11 版本、多于两个桌面、强制结束后的真实键盘输入恢复。逻辑验证不能替代这些集成测试。详细记录见 `TEST-REPORT.md`。

## 构建

在 Windows PowerShell 中从源码目录运行：

```powershell
powershell -NoProfile -File .\build.ps1
```

生成当前目录 `DesktopToggle.exe`。目标为 x64 WinForms，依赖仅为 Windows 自带组件。源码在 `src/DesktopToggle.cs`。

开发者可运行以下检查；它会实际创建缺少的第二桌面、切换并尝试回到原桌面，不删除桌面：

```powershell
.\DesktopToggle.exe --verify "$PWD\verification.txt"
```

写报告后退出。正常用户不需要运行。请先关闭常驻实例，测试期间不要手动切换桌面。
